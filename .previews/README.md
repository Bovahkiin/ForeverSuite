# ForeverSuite previews

The current gallery accompanies ForeverSuite 1.0.7.

| File | Content |
| --- | --- |
| `00-cover.png` | Refreshed brand artwork without a version number or theme count. |
| `01-control-center.png` | Actual in-game Control Center with pinned tools. |
| `02-all-tools.png` | Actual All Tools view with descriptions and direct actions. |
| `03-gear-planner.png` | Actual Gear Planner with loaded equipment entries. |

The three interface previews were captured in WoW Forever and cropped to the
addon windows. No interface content was generated or retouched. Chat and other
addons are outside the crops. Each gallery image is smaller than 2 MB.

The cover is AI-generated brand artwork. The screenshots are separate assets and
show the real addon. Update this gallery when those windows change.
